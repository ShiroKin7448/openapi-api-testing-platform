Target Endpoint: POST /login
OpenAPI Schema Contract properties: { email: [type: string, format: email], password: [type: string, minLength: 8] }, required: ["email", "password"], additionalProperties: false
✓ Strict Validation Mode
✔ 1. Valid Baseline (Hợp lệ)
POSITIVE TEST

  "password": "valid_secret_pass_123"
}
// Dữ liệu sinh đúng định dạng regex email & minLength
Thuật toán: JSON Schema Fuzzer (Generator)
Kỳ vọng: 200 OK
✖ 2. Mutation: MISSING_REQUIRED
NEGATIVE TEST
{
  // <-- Trường "email" (required) bị lược bỏ hoàn toàn
  "password": "valid_secret_pass_123"
}
// Kiểm tra phản hồi khi Client thiếu trường bắt buộc
Đột biến: Loại bỏ thuộc tính trong required[]
Kỳ vọng: 400 Bad Request
⚠ 3. Mutation: TYPE_MISMATCH
NEGATIVE TEST

}
// Kiểm tra Type Validator phía Server
Đột biến: Thay đổi kiểu dữ liệu (Type Inversion)
Kỳ vọng: 400 Bad Request
⚡ 4. Mutation: NULL_VIOLATION
NEGATIVE TEST
{

}
// Kiểm tra xử lý giá trị null không được phép
Đột biến: Tiêm giá trị Null vào non-nullable field
Kỳ vọng: 400 Bad Request
